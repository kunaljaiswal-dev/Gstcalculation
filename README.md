# GST Calculator

This is a simple GST calculator designed for Indian users.

## What it does
- Calculates GST amount
- Adds GST to base price
- Removes GST from total price

## Example Calculation

If base price = ₹1000 and GST = 18%:

GST amount = ₹180  
Total price = ₹1180  

If total price = ₹1180:

Base price = ₹1000  
GST = ₹180  

## Why this project

This project is created to help students, small businesses, and professionals easily understand GST calculations.
